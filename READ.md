# Beauty Product Ingredient Lookup 

- A web app allowing users to search for a beauty / skincare product, select the correct product from the results, and learn more anout its ingredients.

- This product uses 2 API's together.
'The Beauty API' is ised to search for matching products and retreive their ingredients. The chosen ingredient is then used as a search parameter for the 'CosING API' to retrieve cosmetic and regulatory information.

## How it works

- enter brand and product name in search bar
- select correct product from results
- choose an ingredient from the product ingredient list
- view additional information including INCI name, cosmetic functions, EU cosmetic restrictions, warnings when available

## Built with 
- HTML
- CSS
- JAVASCRIPT
- THE BEAUTY API
- COSING API
